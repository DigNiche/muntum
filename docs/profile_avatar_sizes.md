# 공통 프로필 아바타 적용 보고

## 규격

사용자 확인에 따라 반지름이 아닌 **원 전체 가로·세로(지름)** 기준이다.
`ProfileAvatarSize`가 ScreenUtil `.r` 배율을 내부에서 적용한다.

| 등급 | 아바타 가로·세로 | 역할 배지 가로·세로 |
| --- | --- | --- |
| large | 56.r | 20.r |
| medium | 40.r | 16.r |
| small | 24.r | 12.r |

작은 배지 12.r는 요청에 별도 크기가 없어 적용한 값이다.
CURATOR는 curator_badge.svg, MANAGER는 manager_badge.svg를 사용한다.
AUDIENCE 및 역할 없는 사용자는 역할 배지를 표시하지 않는다.

카메라 버튼은 역할 배지가 아니므로 역할 배지 20.r 규격을 적용하지 않는다.
프로그램 포스터의 큐레이터 표시 및 하단 내비게이션 프로필 아이콘은
프로필 사진 아바타가 아니므로 변경하지 않는다.

## 코드 변경

- `lib/components/profile_avatar.dart`: 공통 ProfileAvatar와 세 가지 크기 enum 추가.
  기본 이미지·네트워크 이미지·로컬 업로드 미리보기, 원형 클립, 역할 배지를 한 곳에서 렌더링.
- 기존 화면별 아바타 클래스 9개와 중복 기본 이미지 코드를 제거하고 공통 컴포넌트로 대체.
  기존 user_profile_sheet.dart의 UserAvatar도 standalone 컴포넌트로 교체.
- CurrentUserProfileImageStore의 현재 사용자 이미지 갱신 및 타 사용자 이미지 분리 유지.
  빈 URL/상대 URL 정규화 및 이미지 로드 실패 시 기본 이미지 처리 통일.
- 프로필 수정 미리보기는 저장 전의 로컬 선택/기본 이미지 삭제 상태를 그대로 반영하도록
  현재 사용자 이미지 override를 사용하지 않음.
- 공개/관리자 큐레이션 작성자 모델의 role 파싱 추가.
  관리자 작성자를 일괄 큐레이터로 표시하던 부분을 구분. API 요청은 변경하지 않음.
- 비율 계산 배지를 없애고 size enum의 고정 배지 크기 사용.
  배지는 아바타 레이아웃 박스 안에 배치하여 스크롤 영역에서 잘리지 않도록 함.

## 검증

- 전체 Flutter 테스트 178건 통과. 추가 컴포넌트/모델 테스트 9건 포함.
- 큰/중간/작은 아바타의 실제 레이아웃 치수 및 CURATOR/MANAGER SVG 치수,
  배지 경계, 일반 사용자 배지 없음, 프로필 수정 미리보기 설정, 작성자 role 파싱 검증.
- 기존 프로필 이미지 갱신·바텀시트·작성글·공개 상세·지원 상세 화면 테스트도 전체 실행에 포함.
- 공개 큐레이션 상세 테스트 1건이 이전 배지 컴포넌트 key를 찾다가 실패.
  공통 아바타의 배지 key로 검증을 변경하고 전체 재실행하여 통과.
- 중복 구현 제거 후 남은 unused import 경고 5건 제거.
- Android debug APK 및 iOS 시뮬레이터 debug 빌드 성공.
- 전체 분석에는 이전부터 확인된 정보성 알림 8건이 남음:
  isNew_badge.dart 파일명 1건과 recent_search_widget.dart:37,
  searchbar.dart:99/146, stat_card_widget.dart:42, find_password_screen.dart:100,
  verification_code_screen.dart:209, app_toast.dart:47의 deprecated SVG color 7건.
- 실제 기기에서 모든 화면을 직접 열어 확인한 결과는 아님. 기기별 시각 검증은 미수행.
- 앞선 API 업데이트 및 사용자 작업 중이던 포스터/버전 변경은 유지.
